# Terminal

Supported firmware: **74.00.324**. Select **System > Terminal > Run**.

> [!WARNING]
> The Terminal is a command line with full (root) access to the CMU. A wrong command can damage the system or leave the CMU
> unusable, and the damage may not be reversible. Open it only if you know what you are doing, and only while parked.

A USB keyboard is required. Leave with **HOME on the multicontroller** or by typing `exit`. Keep the USB connected until the
launcher is back: the Terminal runs from it.

The tweak itself installs and changes nothing, on the USB drive or in the CMU's flash.
