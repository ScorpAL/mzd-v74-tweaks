# Getting started

Check that your CMU firmware matches **74.00.324**, the version currently supported
by the included tweaks. Download the development branch and extract it.

1. Copy everything **inside `usb/`** to the root of your USB drive, including
   `jci-autoupdate` and the long filename ending in `.up`.
2. Park the vehicle, keep power on, and insert the USB drive.
3. Read the startup notice. Choose **OK** to open the menu or **Exit** to leave.
4. Read each tweak's description before installing it. Keep the USB connected
   until the result appears.

The package is ready to use. No additional program needs to be installed or
compiled on the vehicle. Before making changes, consider running **System >
Backup JCI**; see [Backup and restore](Backup-and-restore).

If you previously used an early test package without saved installation records,
uninstall those tweaks using their matching old USB package before replacing it.
A missing installed indicator does not prove that an old tweak is absent.
